## 先认识数据：Data Exploration

| 图 | 表示什么 | 怎么理解 |
|---|---|---|
| 01_data_profile | 各年记录数量、零雨比例、正雨量分位数 | 雨量为零是有效观测；大多数记录为零，正雨量另有长尾。不是把缺失填成零。 |
| 02_positive_distribution | 全部正五分钟雨量的对数分箱分布 | 看常见雨量尺度和长尾，横轴不是线性；零雨量不在该图中。 |
| 03_coverage | 各月覆盖率中位数与合格站点数 | 上图只统计有记录站点；下图要求月覆盖率≥90%。下图灰格是无合格站点。 |
| 04_source_gap | 2018年8月逐日原始/清洗记录数 | 4–31日原始数据已经没有记录，不是清洗删掉，更不是没有下雨。 |

实际规模是 48,538,625 条清洗记录、91 个不同站点ID；97.08% 的记录雨量为零。96个年月组合中85个有合格站点。这些数字说明数据量很大，但仍有集中缺口。

## 时间变化：全部月份都在框架内

| 图 | 表示什么 | 怎么理解 |
|---|---|---|
| 05_monthly_amount | 8年×12个月，合格站点月累计量的平均 | 每格站点组成可能不同；灰色不是零。不要把某月全站雨量直接相加当成全国雨量。 |
| 06_seasonality | 各月累计量、降雨频率、湿时段平均量 | 各可用年份等权；阴影是年份最小–最大范围，不是置信区间。 |
| 07_monthly_trends | 每个月在八年中的变化 | 十二个月各一张小图，缺失时断线；各小图纵轴范围不同，绝对大小看05。 |
| 08_annual_totals | 完整日历年的合格站点累计量 | 点是站点，菱形是站点均值。要求年覆盖≥95%且每月≥90%；不合格年份留空，不能拿残缺量冒充全年量。 |
| 09_paired_changes | 相邻年份同月共同站点的变化百分比 | 先匹配同站，再算变化。少于5个共同站点不展示变化；不同配对的站点集合不同。 |
| 09b_paired_support | 上述配对有多少共同站点 | 用来判断09的样本支持。计数图仍保留少于5站的格子；变化图隐藏这些格子。 |
| 10_diurnal | 月份×小时以及各年逐小时降雨频率 | 已扩展到全部合格站点月份；使用新加坡时间和观测数加权，年份曲线的月份组成可能不同。 |
| 11_daily_tails | 各年月日雨量P99和有雨日比例 | 合格月份内还要求日覆盖≥95%；分位数含零雨日，有雨日按>0定义。 |
| 12_sensitivity | 80%、90%、95%覆盖标准下的季节统计 | 真正比较雨量结果，不只是剩余记录数；相近不等于缺失没有偏差。 |

年度结果目前只有2017、2022、2024满足严格规则：分别9、54、29站。这是源数据支持的限制。其它年份仍参与有足够数据的月度分析、跨年同月分析和空间分析，不是从项目里删除。

## 地区图：覆盖八年、十二个月

- `13_spatial_month_01` 至 `13_spatial_month_12`：选同一个月份，并排比较八年。站点颜色是月累计量，标题有站点数。
- `14_spatial_year_2017` 至 `14_spatial_year_2024`：选同一个年份，展示完整十二个月。空白月份标注数据不足。
- `15_regions_month_01` 至 `15_regions_month_12`：同月份的八年规划区热图。颜色是区内合格站点均值；灰色代表无站点支持，点表示参与站点的位置。
- `16_annual_spatial`：八年完整年度累计量地图，采用与08相同的严格规则；不支持的年份明确留空。

所有月度地图共用线性色标，未截断高值；年度地图另用年度色标。现在不画连续插值面，避免让估计看起来像额外观测。规划区均值也不是整个区的面积平均降雨。

交互地图下拉菜单有96个年月，悬停显示站点ID、雨量和覆盖率。`planning_area_monthly.csv` 保存每区每月的站点数及均值，`planning_area_assignments.csv` 保存对应关系；不匹配或歧义站点不强行归区。

## 报告怎么读

英文报告按“研究问题→Data Exploration→清洗与方法→月份季节性→跨年和年度累计量→日内及日雨量→空间→敏感性与局限”展开。图不再自带海报式大标题和长脚注，LaTeX图注与正文一起解释样本和结论。

正文图号由LaTeX自动生成，与图文件前缀不是同一套编号。完整46张主图/补充图都在本地图集中，不需要把重复的96个地图面板全部塞进正文。
